Weight behaviour

The weight axis runs −2 to +2 px and is relative: it changes a vector's apparent thickness by that amount. The two directions are implemented differently, because paint can be added to a shape but never removed.

DirectionMechanismCurves
Positive Fill-matched stroke, CENTER aligned Preserved exactly
Negative Path rewritten by geometric offset Flattened to polylines

A CENTER-aligned stroke of w widens a wall by w, but a geometric offset of d widens it by 2d — it moves both edges. The plugin therefore offsets by delta / 2, so −0.5 removes exactly what +0.5 adds. The sweeps below are drawn from that same arithmetic.

Returning to 0 restores the stored original path byte-for-byte, so nothing is lost by exploring. Geometry here is hand-authored and computed analytically, keeping this page self-contained and free of third-party icon artwork.
